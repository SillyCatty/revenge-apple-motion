# Apple Motion Plugin for Revenge / Vendetta

Brings Apple HIG motion physics (harmonic springs and rubber-banding) to Discord mobile.

## Features
- **Damped Harmonic Springs:** Replaces abrupt transition curves with momentum-aware springs (`smooth` by default).
- **UIKit Rubber-Banding:** Prevents harsh wall-stops during drag gestures.

## Installation in Revenge / Bunny
1. Push this repository to GitHub.
2. In Revenge settings inside Discord, open **Plugins**.
3. Tap **Install Plugin** and paste your GitHub link / raw `index.js` link.
